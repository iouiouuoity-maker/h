## Автоматты тексеру

Команда: `node --test tests/*.test.mjs` (Node 24+).

17 тест: 11 Worker/D1 интеграциялық тексеру, 5 оқу логикасы/asset тексеруі, 1 V1→V2 миграциясы. Worker тесттері Node SQLite және D1-ге ұқсас адаптермен орындалды; бұл өндірістік Cloudflare D1 емес.

- Құпиясөз тұзы/хэші, login, admin/teacher/student рөлдері.
- Басқа origin және рұқсатсыз материал өзгерту/аккаунт басқару әрекеттері.
- Материал жоба→жариялау→іздеу/санат→version conflict→мұрағат.
- Жарияланған материалдың AI шақыруына контекст ретінде берілуі.
- Жауап/сауалнама сақтау; екі оқушының жеке деректерін оқшаулау.
- Мұғалім бағасы мен пікірінің оқушы нәтижесіне берілуі, қатар бағалау қақтығысы.
- Аккаунт құру, duplicate code, бұғаттау, logout және сессия жарамсыздығы.
- Сервер бекіткен зерттеу тобын оқушының жалған мәнмен ауыстыра алмауы; салыстыру тобына AI жабық болуы.
- Материал мен күн сәйкес келмесе жауап сақтау кері қайтарылуы.
- Жаңа support өрістерін қосу/өңдеу/қайта оқу және көлем шектері.
- AI binding жоқ, провайдер лимиті, сұрау ұзындығы, сұрау жиілігі.
- 1 және 14-күн материалдарына AI көмегінің серверде жабық болуы.
- Файл қоймасы жоқ күйі; жалған PNG мазмұнының серверде бұғатталуы.
- Келесі күн, day-06→6/custom→0, бастапқы/соңғы жазбаның дұрыс таңдауы.
- Барлық 6 сөйлесу жағдайының сұрақтары, күндері және жергілікті иллюстрациялары.
- 16 бастапқы материалдың snapshot-ы және мұқаба файлдары.
- V1 аккаунттарының сақталуы; өзгертілмеген алғашқы сабақтың жаңаруы; мұғалім өзгерткен бастапқы/custom мазмұнның үстінен жазылмауы.

Қосымша: JavaScript синтаксисі, 10 HTML беттің жергілікті сілтемелері мен module import жолдары, SQL schema+seed және 14 оқу тірегі жиыны тексерілді. ZIP CRC қаптау кезінде тексеріледі.

## Браузерде нақты орындалды

- Жаңа басты бет пен жергілікті SVG көрінісі.
- Кітапханаға өту, бастапқы 16 материалдың оқуға арналған режимі, іздеу мен бос нәтиже күйі.
- A2→B1 таңдағанда кафе тапсырмасының өзгеруі.
- «Өзім байқап көремін» режимінде тіректердің жасырылуы.
- 60 секунд таймерін бастау, үзіліс батырмасын қолдану.
- 6-күн жауабын күнделікке өткізу: тақырып, мәтін және 6-күн дұрыс берілді; авторизациясыз «серверге сақтау» жабық.
- Бұрын терілген жауаптың сол вкладкада қалпына келуі.
- Сөйлесу жағдайының «Басқа сұрақ» батырмасы.
- AI prompt chip мәтінді дайындайды; тексерілген жіберу әрекетінде сервер URL-і бос болғандықтан нақты бапталмаған қате көрсетілді. Жалған AI жауабы берілген жоқ.
- 390 px контейнердегі mobile мәзірі ашылды; native dialog фокусы жабу батырмасына өтті.
- 390/768 px iframe контейнерлерінде layout өлшенді: document scrollWidth пен clientWidth тең.
- 320 px iframe контейнерлерінде library, studio, scenarios, home, survey, challenge беттерінде scrollWidth==clientWidth (ішкі viewport 305 px, себебі scrollbar орын алады).

Бұл browser-frame responsive QA. Нақты iPhone/iPad аппаратында тест жасалған жоқ.

## AI mock пен тірі модель айырмасы

Тесттегі env.AI.run — TEST DOUBLE деп белгіленген mock. Ол сұрау, контекст және қате өңдеуді тексереді. Өнім Worker-інде mock жауап жоқ: модельге env.AI.run арқылы сұрау жіберіледі. Авторлық үлгі жауаптар AI генерациясы ретінде көрсетілмейді.

## Орындалмаған тексерулер

- Нақты GitHub Pages домені және жаңа/жаңартылған Worker-мен production CORS.
- Cloudflare D1 migration, R2 upload/download, Workers WebCrypto CPU бюджеті.
- Тірі Workers AI генерациясы, neuron лимиті, модель шарттарын аккаунтта қабылдау.
- Екі нақты құрылғыдан login→CMS→тапсырма→бағалау толық өндірістік E2E.
- iOS микрофон/диктовка/TTS, толық screen-reader және тәуелсіз қауіпсіздік аудиті.
- Админ редакторындағы алдын ала қараудың браузерлік E2E; backend support сақтау тесті орындалды.
