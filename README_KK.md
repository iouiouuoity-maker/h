# SPEAK FREE V2 — GitHub Pages + Cloudflare

Мәртебе: код дайын; осы жинаққа арналған Cloudflare Worker, D1 және R2 аккаунтта әлі құрылмаған; GitHub Pages-ке бұл нұсқа жарияланбаған. Алдыңғы chatgpt.site сілтемесі — басқа, қарапайым нұсқа. Жинақ оны өзгерткен жоқ.

Жоба: «Can AI Help Students Speak English Without Fear?» Автор: Нұржанқызы Фариза, 2026–2027. Ұйым мен жетекші файлда толық берілмеген, ойдан қосылған жоқ. Интерфейс қазақша, сөйлеу тапсырмалары ағылшынша. 8-сынып, A2–B1 үшін авторлық оқу бейімдеуі.

## Жинақ құрылымы

- index.html — ықшам басты бет.
- library.html — ортақ кітапхана, іздеу, санат, 9 материалдан беттеу. Сервер бапталмаса, бастапқы 16 материал оқуға қолжетімді (осы күйі анық белгіленген).
- scenarios.html — 6 авторлық сөйлесу жағдайы: рөлдер, тіркестер, ауыстырылатын сұрақ және студияға өту.
- material.html?id=… — жеке материалдың өз URL-і.
- practice.html?day=… немесе ?material=… — A2/B1 тапсырмалары, тіректермен/дербес режим, 30/60 секунд таймер және үзіліс, уақытша жауап жобасын қалпына келтіру, браузерлік дыбыстау/диктовка, Workers AI диалогы.
- challenge.html — бастапқы файлдағы 14 күндік тақырыптар.
- survey.html — 5 сұрақ + негізгі қиындық, жеке карта, серверде сақтау.
- progress.html — жауап, күнделік, 4 көрсеткіш, 1/14-күн салыстыруы, мұғалім бағасы.
- research.html — әдіс, теория, зерттеу тәртібі, шектеулер, файлдағы әдебиеттер.
- cabinet.html — login/logout, материал редакторы, бағалау, зерттеу экспорты, аккаунттар.
- js/config.js — сервер URL-і енгізілетін жалғыз файл.
- cloudflare/worker.js — бір файлдық ESM Worker, сыртқы npm тәуелділігі жоқ.
- cloudflare/schema.sql және seed.sql — D1 кестелері және 16 бастапқы материал.
- assets/voice.svg — нақты жергілікті иллюстрация; style.css — барлық стиль.
- tools/password-hash.html — алғашқы әкімші үшін офлайн хэш генераторы.
- tests/worker.test.mjs — Node 24+ жергілікті SQLite/D1 адаптерімен сервер тесттері.
- docs/REQUIREMENTS.md — талаптардың сәйкестік кестесі.
- docs/VERIFICATION.md — нақты тексеру және қалған аккаунттық тексерулер.

## Егер V1 нұсқасын БҰРЫН орнатқан болсаңыз

Жаңа бос базаға төмендегі миграцияны қолданбаңыз — онда schema.sql жеткілікті.

1. Қолданыстағы D1-дің резервін/экспортын алыңыз.
2. D1 Console-де `cloudflare/migration-v2.sql` операторларын **бір рет** орындаңыз. Ол `users.study_group` пен `materials.support` өрістерін қосады. Қайта орындау duplicate column қатесін береді; бұл жағдайда деректі өшіріп немесе базаны қайта құрып жібермеңіз.
3. Қаласаңыз `cloudflare/upgrade-lessons-v2.sql` орындаңыз: ол мұғалім өзгертпеген бастапқы 14 сабаққа жаңа оқу мазмұнын қосады. Мұғалім өзгерткен body/version/author бар жазбалар жаңартылмайды.
4. Worker кодын және GitHub интерфейсін бірге жаңартыңыз. Бұрынғы нақты `js/config.js` URL-ін сақтаңыз — осы сайттың өз Worker-ін жаңарту үшін жаңасын ойлап табу қажет емес. Басқа жобаның Worker-ін қолданбаңыз.
5. Кабинетте зерттеу топтарын тексеріңіз: бұрынғы аккаунттар default AI тобында. Қажет қатысушыларды салыстыру тобына ауыстырыңыз. Браузер бетін жаңартыңыз.

Жаңа жобаға төмендегі қалыпты қадамдар қолданылады.

## 1. GitHub дайындау — Dashboard

1. GitHub-та жаңа репозиторий ашыңыз, мысалы `speak-free`. Нақты аккаунт атауы бұл тапсырмада берілмеген.
2. ZIP-ті ашыңыз. `SPEAK_FREE_GITHUB_CLOUDFLARE` ішіндегі файлдарды репозиторийдің түбіріне жүктеңіз. `index.html` түбірде тұрсын, қосымша қапшық ішінде қалмасын.
3. `tools/` қалтасын жарияламауға болады. Онда құпия жоқ, бірақ бұл тек иесіне арналған құрал.
4. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. GitHub берген нақты мекенжайды сақтаңыз. Жоба репозиторийі үшін ол `https://АККАУНТ.github.io/РЕПОЗИТОРИЙ/` түрінде болады. Бұл — үлгі, нақты жарияланған URL емес.
6. CORS origin-і мекенжайдың тек домен бөлігі: `https://АККАУНТ.github.io`. `/РЕПОЗИТОРИЙ/` қоспаңыз. Custom domain болса, сол нақты HTTPS origin қолданылады.

## 2. ЖАҢА Cloudflare D1 — Dashboard

1. Cloudflare Dashboard → Storage & databases → D1 → Create database. Осы жобаға бөлек `speak-free-db` дерекқорын жасаңыз.
2. Дерекқор → Console. `cloudflare/schema.sql` ішіндегі SQL-ді орындаңыз. Console бір сұраудан ғана қабылдаса, CREATE операторларын жеке-жеке іске қосыңыз.
3. `cloudflare/seed.sql` ішіндегі INSERT операторларын орындаңыз. 14 күндік жоспар және 2 қосымша тапсырма қосылады. Қайта импорттау бар материалдарды өшірмейді.
4. Компьютерде `tools/password-hash.html` ашыңыз. ADMIN сияқты код пен өзіңіз таңдаған кемі 12 таңбалы құпиясөзді енгізіңіз. «Хэш пен SQL жасау» батырмасын басыңыз.
5. Шыққан SQL-ді D1 Console-де орындаңыз. SQL-де ашық құпиясөз болмайды. Хэшті де ашық репозиторийге салмаңыз. Құпиясөзді пароль менеджерінде ұстаңыз.
6. Сайтта алғашқы әкімшімен кіргеннен кейін «Аккаунттар» арқылы мұғалім мен S01, S02 сияқты оқушы аккаунттарын жасаңыз. Жалпыға ашық өздігінен тіркелу әдейі жоқ: балалардың аккаунттарын әкімші береді.

## 3. ЖАҢА Cloudflare Worker — Dashboard

1. Workers & Pages → Create application → Create Worker / Start with Hello World. Жаңа, бірегей атау беріңіз. Бұрынғы жобаның Worker-ін қолданбаңыз.
2. Edit code: `cloudflare/worker.js` файлын толық қойыңыз. Deploy басыңыз.
3. Worker → Bindings → Add binding → D1 Database: Variable name `DB`, жоғарыда жасалған D1 дерекқорын таңдаңыз.
4. Add binding → Workers AI: Variable name дәл `AI`.
5. Settings → Variables and Secrets: Text variable `ALLOWED_ORIGIN` = GitHub Pages-тің нақты HTTPS origin-і (жолсыз, соңғы `/` белгісінсіз).
6. Secret `IP_SALT` жасаңыз: пароль менеджерінен алынған кемі 32 кездейсоқ таңба. Бұл IP-ді күн сайын өзгеретін тұздалған хэшке айналдыру үшін қолданылады. Нақты IP базаға жазылмайды. Secret-ті GitHub-қа салмаңыз.
7. Settings → Triggers / Cron Triggers: күнделікті `0 3 * * *` қосыңыз. Ол мерзімі өткен сессиялар мен лимит есептегіштерін тазалайды. Күнделік, нәтиже, материалдар бұл тазалауда өшірілмейді.
8. Өзгерістерді Deploy арқылы қолданыңыз. Worker Dashboard-да берілген НАҚТЫ `https://....workers.dev` URL-ін көшіріңіз. Бұл жинақта жалған Worker URL-і жоқ.
9. Алғашқы AI сұрауы модель шарттарын қабылдауды талап етсе, аккаунт иесі Cloudflare Dashboard арқылы өзі қабылдауы керек. Бұл аккаунттан тыс осы жерде орындалмаған.

## 4. Міндетті емес R2 файл қоймасы — Dashboard

1. R2 Object Storage → Create bucket: осы жобаға бөлек қойма жасаңыз. Аккаунт R2 іске қосуды/төлем әдісін сұрауы мүмкін; оны иесі шешеді. R2-сіз сыртқы HTTPS сілтемелері жұмыс істейді.
2. Worker → Bindings → R2 bucket → Variable name `FILES` → осы bucket.
3. Bucket public access/r2.dev қоспаңыз. Файлдарды Worker жарияланған материалмен байланысын тексеріп береді.
4. Deploy. Кабинетте PNG/JPEG/WebP/PDF файлдарын 5 МБ дейін жүктеуге болады. Түрі, өлшемі және файл сигнатурасы серверде тексеріледі.
5. Мұқабаны жүктеу материалды бірден жарияламайды. Редакторда мәртебесін таңдап сақтаңыз.
6. Видео жүктеу жоқ. YouTube/Vimeo сілтемесін бөлек өріске енгізуге болады.

## 5. Бір ғана frontend конфигурациясы

GitHub-та `js/config.js` файлын ашыңыз:

```js
export const AI_API_URL = '';
```

Бос жолға 3-қадамдағы жаңа Worker-дің нақты HTTPS origin-ін енгізіңіз. Соңына `/` қоспаңыз. Бұл мекенжай барлық login, деректер, файлдар және AI әрекеттеріне ортақ. Басқа файлда URL ауыстыру қажет емес. Commit жасаңыз, Pages жариялануын күтіңіз.

Келушіде API key, Worker URL енгізу формасы, AI серверін таңдау немесе «AI қосу» батырмасы болмайды. Баптау жоқ кезде серверлік әрекет нақты қате береді, жалған сәттілік не AI жауабы көрсетілмейді.

## 6. Басқару тәртібі

- Әкімші: аккаунт құру, бұғаттау/қайта қосу, құпиясөз жаңарту, материалдар және бағалау.
- Мұғалім: материал қосу/өңдеу, жоба сақтау, жариялау/мұрағат, барлық тапсырма мен сауалнаманы қарау және бағалау.
- Оқушы: жарияланған материалдар, AI, өзінің нәтижелері/сауалнамасы және мұғалім пікірі.
- Мұғалімдер бір зерттеудің ортақ ұжымы ретінде барлық оқушы нәтижесіне қол жеткізеді. Бөлек мектеп/сыныпқа tenancy isolation жасалмаған.
- Редактордағы «Оқу тіректері» арқылы сөздік, сөйлем бастаулары, B1 тапсырмасы мен авторлық мысал қосылады. Бұл өрістер материал бетінде, студияда және AI контекстінде қолданылады; код өзгерту қажет емес.
- «Алдын ала қарау» редактор мәтінінің қауіпсіз нұсқасын көрсетеді. Ол серверге сақтауды алмастырмайды.
- Жоба/мұрағат негізгі кітапханада және AI контекстінде шықпайды. Жариялау кезінде автоматты пайда болады.
- Бір материалды қатар өңдегенде version тексеріледі; 409 қақтығысы болса, өзгеріс үнсіз үстінен жазылмайды. Мәтінді көшіріп алып, жаңартылған материалды ашыңыз.
- Жауапты сақтау → мұғалімнің «Бағалау және зерттеу» бөлімі → баға/пікір → оқушының «Менің прогресім» бөлімі. Баға оқу кері байланысы, ресми емтихан нәтижесі емес.
- Зерттеу тобын әкімші аккаунтқа бекітеді. Оқушы топты жауап сақтау кезінде өзгерте алмайды. Салыстыру тобының авторизацияланған аккаунтына AI endpoint-і серверде жабық. Бұл сайттан тыс AI қолдануды бақыламайды.
- Соңғы 500 нәтиже/сауалнама кабинетте көрсетіледі. Материалдар 9 жазбадан беттеледі; зерттеу 20 оқушы/14 күн масштабына сай. Ірі зерттеу үшін нәтижелерге қосымша серверлік беттеу керек.

## AI моделі және лимиттер

Модель: `@cf/meta/llama-3.1-8b-instruct-fp8`. Ресми модель беті мен баға тізімі 2026-11-02 күні тексерілді. Бұрынғы қарапайым `llama-3.1-8b-instruct` нұсқасы deprecation тізімінде болғандықтан қолданылмады.

Workers AI Free жоспарының күніне 10 000 neuron бөлінісі аккаунттағы барлық AI қолдануға ортақ. Бұл «шексіз тегін» дегенді білдірмейді; шек біткенде қате көрсетіледі. Тариф пен модель қолжетімділігі өзгеруі мүмкін.

- AI: IP-дің күндік тұздалған хэшіне 8 сұрау/минут және 60/күн; бүкіл жобаға 250/күн. Мектептің ортақ IP-і болса, лимит ортақ болады. Global шек neuron бюджетіне дәл кепіл болмайды.
- Хабарлама 1800 таңба, алдыңғы 6 хабарлама, жауап max_tokens 320.
- Контекст — таңдалған жарияланған материал, болмаса соңғы 5 жарияланған материал. Vector search/RAG embedding жасалмаған.
- Сервер күтуі 25 секунд, браузер 35 секунд. Timeout кезінде жалған жауап берілмейді. Сервер таймауты провайдерде басталған есептеуді міндетті түрде тоқтатпайды.
- AI — мәтіндік модель. Браузерлік сөйлеуді тану мен TTS модельдің аудио түсінуі немесе айтылым бағасы емес.
- Дауыс, фото, құжат немесе күнделік автоматты AI-ға жіберілмейді. Оқушы чаттағы мәтінді өзі жіберіп, келісім белгісін қояды.

## Қауіпсіздік және сақтау

PBKDF2-SHA256, 100 000 итерация, әр құпиясөзге кездейсоқ 128-bit salt. Сессия токені 256-bit, D1-де тек SHA256 хэші, 8 сағат. Frontend sessionStorage тек осы вкладканың уақытша bearer токенін және сақталмаған жауап жобасын ұстайды; ортақ деректер D1-де. Сессия URL-ге салынбайды. Рөл мен active күйі әр сұрауда серверде тексеріледі. Logout сессияны жояды; құпиясөз ауысқанда/аккаунт бұғатталғанда барлық сессиясы жабылады.

Bearer токен қолданылады, cross-site cookie-ге тәуелді емес. CORS бір origin-ге шектелген, бірақ CORS API аутентификациясын алмастырмайды. Public AI нүктесіне бот шабуылына қарсы Turnstile қосылмаған; қарапайым D1 лимиттері бар. Public AI-ды кең аудиторияға шығарғанда Turnstile/WAF қосу орынды.

Барлық SQL параметрленген, пайдаланушы контенті HTML ретінде орындалмайды. SVG upload тыйым салынған. Сыртқы суреттер үшін тұрақты, сенімді HTTPS URL қолданыңыз; жергілікті негізгі иллюстрация жинақта бар. Google Fonts қолжетімсіз болса Arial/Georgia fallback бар. Дыбыс және диктовка браузерге тәуелді.

Базада аты-жөн, телефон, email қажет емес. Қолданушы коды, тапсырма мәтіні және прогресс сақталады. Алдын ала retention мерзімі/өздігінен аккаунт өшіру интерфейсі жасалмаған: иесі сақтау мерзімін бекітіп, қажет деректерді D1 арқылы өшіруі керек. Cloudflare D1 backups/export аккаунтта басқарылады; резерв автоматты түрде бөлек жерге көшірілмейді.

## CLI — тек балама

Dashboard жеткілікті, Wrangler міндетті емес. CLI қолдансаңыз:

```bash
cd cloudflare
npx wrangler login
npx wrangler d1 create speak-free-db
```

## Міндетті соңғы аккаунттық тексеру

Дәл қазір кодтың тесттері өтуі өндірістегі байланыс орнатылды деген сөз емес. Deploy соңында:
1. Нақты GitHub Pages URL-і мен мобильді беттерді ашыңыз.
2. Admin → мұғалім және екі оқушы коды.
3. Жоба қосыңыз: оқушы көрмеуі керек. Жариялаңыз: кітапханада, іздеуде және AI контекстінде көрінуі керек.
4. Екі вкладкада бір материалды өзгертіп, conflict тексеріңіз; мұрағаттан кейін оқушыға жабық болуы керек.
5. Оқушы 1 жауап сақтасын, оқушы 2 көрмесін; мұғалім бағаласын, оқушы 1 пікірін көрсін.
6. Logout соңында ескі токен өтпеуі керек.
7. AI-ға нақты сұрау жіберіп, тірі модель жауабын тексеріңіз. Binding/лимит қателерін қараңыз.
8. R2 болса файл жүктеңіз, материалмен жариялаңыз, екі құрылғыдан ашыңыз.

Осы қадамдар бұл сессияда аккаунтқа кіру болмағандықтан орындалмаған.


## V2-де не жақсарды?

10 HTML бет (9 негізгі бөлім + жеке материал), 7 жаңа жергілікті SVG иллюстрация, mobile bottom navigation және толық модаль мәзір, 6 сөйлесу жағдайы, 14 мазмұны бөлек мини-сабақ. Бағдарлама A2 тапсырмасынан B1-ге өтуге, көмекші тіректерді жасыруға мүмкіндік береді. 1 және 14-күн сынақтары бірдей A2 ережесінде, дайын мысалсыз және AI көмегінсіз өтеді.

Негізгі иллюстрациялар — жинақтағы жергілікті SVG; олар ImageGen нәтижесі немесе пайдаланушы фотосы емес. Мысал жауаптар — авторлық оқу материалы, генеративті AI-дың жаңа жауабы ретінде көрсетілмейді. Алты кіріспе сөйлесу жағдайы — алдын ала дайындалған оқу көріністері; жаңа материалдар кабинет арқылы негізгі кітапханаға қосылады.

Сервер әлі бапталмаса, тек оқу материалдары мен жергілікті жаттығулар ашылады. Бұл режимде ортақ сақтау, login және AI генерациясы жұмыс істеп тұр деп көрсетілмейді. Сервер URL-і барда қате шықса, сайт ескі көшірмеге үнсіз ауыспайды.

Сақталған прогресс қана келесі күн карточкасында, күнтізбе белгілерінде және уақыт диаграммасында көрсетіледі. Кітапхана іздеуі мен бет нөмірі URL-де сақталады. Бастапқы/соңғы өлшемді салыстыру үшін автоматты бағалау емес, өзің не мұғалім енгізген көрсеткіштер қолданылады.
